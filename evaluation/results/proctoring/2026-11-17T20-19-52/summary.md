## Not simulated (test manually)

- **(e) Opening and closing DevTools**: Playwright cannot open or close DevTools in a running page; it can only launch Chromium with DevTools already open. Test manually: F12, wait, F12.
- **Real OS notification (toast) appearing**: Generated by Windows, outside the browser; Playwright cannot raise one. Test manually, e.g. with a calendar reminder or a chat message.
- **Opening another app (e.g. Calculator) / Alt-Tab**: OS-level focus changes are outside Playwright's control. Test manually.
- **Physical Esc key / F11**: Playwright's key press reaches the page but not the browser's fullscreen handler, so it never leaves fullscreen (row b1). Row b2 applies the effect of a real Esc (leaving fullscreen) instead. Test the real key manually.
- **Real window resize**: Playwright can only resize the page viewport, not the OS window, and a fullscreen window can't be resized without leaving fullscreen first (see b2). Test manually by dragging a window edge after leaving fullscreen.
- **Real tab switch within one window**: Playwright opens the second page as a separate window, so the quiz loses focus (blur) but is not hidden; a same-window tab switch would also hide the page (visibilitychange). Not measured here; test manually.
- **Real network outage (Wi-Fi off)**: Simulated only by Playwright's offline mode, which blocks the page's requests but does not change the OS network state.
- **Firefox and Safari/WebKit**: Playwright's Firefox and WebKit builds are blocked on this PC by Windows Smart App Control, and Firefox/Safari are not installed. Test manually in real Firefox (and Safari on macOS).
